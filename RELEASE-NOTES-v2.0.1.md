# EC-FIX-IT v2.0.1 — restore extension popup

- Clicking the extension icon opens EC-FIX-IT as a normal toolbar popup again.
- Parameters, Parameter Fixer, Checker and Review remain inside the extension.
- No automatic new dashboard tab or detached window. Detach remains an explicit action.
- The GitHub Pages dashboard is optional, opened only using Open hosted dashboard in the popup.

Update by replacing the existing unpacked extension files and clicking Reload. Close old detached windows/dashboard tabs and reopen using the toolbar icon. Do not uninstall if you want to preserve Review items.

The normal popup runs its bundled interface. Hosted UI changes affect the optional hosted dashboard; the popup and engines still require extension updates.
