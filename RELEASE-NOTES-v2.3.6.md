# EC-FIX-IT v2.3.6 — persistent extension panel

- Clicking the extension toolbar icon opens EC-FIX-IT in the browser side panel. Clicking the creative no longer dismisses the tools.
- The panel follows active-tab changes within its browser window and rebinds when navigating to a different creative. Date/language query changes keep the panel open.
- Side-panel layout adapts to its available width. Existing tabs, review collection, checker and optional detached window remain available.
- Automatic updates already wait for open side panels to close.

Verified toolbar/manifest configuration, tab/window isolation, creative navigation, query-only navigation and updater idle deferral with automated fixtures. Live browser interaction was not exercised.

After updating, reopen EC-FIX-IT from its toolbar icon. Close it with the side panel close button.
