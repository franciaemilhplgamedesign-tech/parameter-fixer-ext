# EC-FIX-IT extension

Chrome and Microsoft Edge extension for SIP/MIP parameter testing, HTML fixes, automatic local source checks, compression and screenshot review.

## Download and install

Get the ZIP from the [latest release](https://github.com/franciaemilhplgamedesign-tech/parameter-fixer-ext/releases/latest). Extract it to a permanent folder, enable Developer mode on your browser extensions page, choose Load unpacked, and select the folder containing manifest.json. Enable Allow access to file URLs for local HTML inspection.

To update: replace your installed extension files, click Reload, then close and reopen the extension window.

## Tools

- Parameters: date/language overrides for AppLovin iterations, file previews and localhost; automatic holiday ranges and optional auto-refresh.
- Parameter Fixer: supported date/language patches for current or bulk HTML files.
- Checker: MRAID/source checks, MIP end-scene packaging, WebGL/network safeguards, selected MIP 5 MB or SIP 3.4 MB limits, and compression.
- Review: screenshots, original local HTML collection, review-package export and experimental transfer to the configured ecomm checker.

See [v1.9.7 release notes and Slack announcement](RELEASE-NOTES-v1.9.7.md) for changes, installation details and limitations. Checks are static review aids, not certification. Verify fixed creatives in the target ad container. Live ChatGPT transfer remains unverified.
